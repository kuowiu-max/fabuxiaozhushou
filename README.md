# 发布小助手

可直接导入 AI 的技能。输入门店名称，以消费者视角生成自然口吻的原创文字，并从正常可访问的小红书帖子、美团评论页获取对应照片。无需网页或本地部署。

## 使用

1. 支持技能导入的 AI：下载并导入 [发布小助手.zip](downloads/发布小助手.zip)。
2. 没有技能入口的聊天软件：上传 [发布小助手.md](downloads/发布小助手.md)，让 AI 按文件规则工作。
3. 发一句：“使用发布小助手：门店名称，城市。”

之后可以直接说“短一点”“换标题”“自然一点”“只给正文”。有同名门店时会询问城市或分店，也支持店铺链接和清晰截图。

用于大众点评分成时输入：“使用发布小助手，大众点评分成：门店名称，城市。”已依据用户于 2026-10-09 提供的“笔记创作分成活动规则”截图适配[指定活动](https://cube.dianping.com/cube/block/aa1a7b35bf4b/334177/index.html)：个人账号诚信分 12 分、系统邀请、确认授权后参与；现金收益在次月 5 日后的工作日可提现。收益由多个维度综合计算，无固定单篇金额保证。

用户另行提供的内容建议为图文不少于 **6 图、200 字**；视频不少于 **30 秒、200 字**。分成模式默认图文正文约 220–300 字、优先 6 张照片，缺素材按实际交付；用户选视频时可整理脚本／配文，是否能交付视频取决于 AI 实际工具与真实素材。保留原文“建议”的性质，不宣称达到数量就符合全部要求。

用户已补充确认本活动**允许外站照片，AI 内容不受限**。技能按此使用对应门店的真实外站照片，并强化自然写作：减少广告套话、夸张形容词、整齐排比和空泛总结，围绕已核实细节写一至两段；不再反复要求本人实拍或确认 AI 是否允许。

外站图与 AI 内容的允许状态依据为用户确认，不是已直接核验的官方条款。网页在维护环境被网络代理拦截，授权协议全文尚未取得；其他条款依据为用户提供的截图及补充文字，未直接在线验证。出处与适配范围见 [活动适配说明](skills/发布小助手/references/dianping-revenue.md)。

## 实际能力

- 核对具体门店、分店及来源，不混用不同门店的信息。
- 文案默认用消费者“我”的第一人称，像自己向朋友分享消费体验；把你已确认的实际点单、花费和感受直接写成自己的经历。仅有门店资料时表达消费选择或计划，不补造到店和口味感受。避免模板腔和“作为 AI”等自我说明，用真实资料原创表达，不承诺通过 AI 检测。
- 从可访问的真实帖子或评论发现、下载公开照片，普通模式默认 3–6 张，分成模式优先 6 张。
- 默认交付只给文案和照片，不附照片出处、来源清单或素材记录文件。具备文件工具时导出只含文案和编号照片的素材包；缺少图片或文件能力时提供真实图片链接，不编造附件。

**技能不会给 AI 新增联网、浏览器、登录权限或图片工具。** 能否访问小红书、美团取决于该 AI 实际提供的工具和站点访问状态。普通聊天软件上传提示词不等于安装了抓取工具。

内部处理区分外站照片与自有／授权原图，默认交付不附来源标签。公开可见不等于取得转载授权；下载保留原图，不额外添加或擅自去除水印。结果不自动发布。

本次分成活动按用户确认可使用外站评论图，交付不附照片出处，不假称本人实拍或已有摄影者授权。自然写作不虚构消费体验，也不保证检测结果、审核或收益。

## 文件

- `skills/发布小助手/`：完整技能及资源，`SKILL.md` 内部名称为“发布小助手”。
- `downloads/发布小助手.zip`：供 AI 导入的同名技能包。
- `downloads/发布小助手.md`：普通对话可上传的单文件提示词。
- 原 `publish-helper.zip`、`publish-helper.md` 下载文件保留为同内容别名，兼容旧链接。
- `downloads/release.json`：版本、大小及 SHA-256。

包内脚本由具备执行能力的 AI 在其环境中使用，无需用户本地部署。完整技能见 [SKILL.md](skills/发布小助手/SKILL.md)。以前版本的网页文件保留在仓库，使用技能无需运行它们。

## 开发维护

以下仅供维护仓库，不是用户使用步骤：

```sh
npm run build:skill
npm run check:skill
npm test
npm run test:materials
```

打包使用 Node.js 22+，可选图片下载／素材打包脚本使用 Python 3.10+ 标准库。脚本不搜索页面、不绕过登录、不处理验证码或去除水印。源码更新后重新生成 ZIP 和提示词，CI 校验发布内容一致性。仓库不保存用户照片、登录资料或真实 API 密钥。
