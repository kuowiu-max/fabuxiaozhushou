# 发布小助手

手机和电脑均可使用的门店素材工作台。输入门店名称和城市，打开检索入口，整理有出处的参考资料、自有或授权原图，并形成可编辑的文案草稿。通用版可将资料和提示词复制到豆包、DeepSeek、ChatGPT 等 AI 软件，无需 API 密钥。

## 直接在 AI 中使用

不想使用网页，可以导入 [发布小助手技能包](downloads/publish-helper.zip)。支持 Skills 的 AI 按自身导入入口加载后，只需输入“使用发布小助手：门店名，城市”。

没有技能导入功能的聊天软件，可上传 [发布小助手提示词](downloads/发布小助手提示词.md)，让 AI 读取并按规则工作。这是对话指令，不会新增软件本来没有的联网或图片工具。完整说明见 [技能说明](skills/publish-helper/README.md)。

## 当前功能与边界

- 门店检索入口：小红书站内搜索、大众点评页面的搜索引擎检索。它们是外部检索入口，**没有自动抓取或验证搜索结果**。
- 记录来源链接和参考内容；已核实事实与参考资料分开保存。
- 手机原图导入，IndexedDB 本机保存，ZIP 导出文案、来源记录和原始图片文件。
- 资料模板整理、手动编辑、文案复制、支持浏览器分享；可复制 AI 提示词，粘贴 AI 返回的内容。
- 可选服务端 DeepSeek/OpenAI 接口；无需配置也可完成通用版工作流。
- 支持 GitHub Pages 项目子路径和离线页面缓存。

不自动发布到任何平台，不绕过登录或反爬限制，不自动删除他人图片水印。图片导出保留原始字节，不添加水印；已有水印不会消失。图片需用户自行提供自有或授权原图。没有实际到店时，草稿按资料介绍编写，不编造亲身消费经历。AI 草稿仍需人工核对。

## 本地运行

需要 Node.js 22 或更高版本。无需安装第三方依赖：

```sh
cd /workspace/daxiaroom
npm test
npm start
```

默认在本机 4173 端口运行。开发服务器默认只监听本机；手机访问需要部署到 HTTPS 网站，或自行配置受信任的局域网服务。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml`，推送到 `main` 时先运行测试，再部署 `public` 目录。

仓库所有者需在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。如果仓库为私有，确认当前 GitHub 方案支持 Pages；不要为了部署而自动改为公开仓库。

部署成功后，地址以 GitHub Actions 部署输出和 Pages 设置显示的 URL 为准。首次启用 Pages 后，可在 Actions 页面选择 **Deploy Publish Helper → Run workflow** 重跑。不要将工作流文件存在或推送成功等同于网站已经上线。

GitHub Pages 仅发布 `public/`。它不能运行 `server.mjs`，不能保存服务端 AI 密钥，通用版全部核心功能仍可运行。

手机打开部署后的 HTTPS 地址，可以通过浏览器“添加到主屏幕”使用。不同手机浏览器的安装、下载和系统分享支持存在差异。

## 可选 AI API

仅适用于运行 Node 服务的部署方式。将 `.env.example` 复制为 `.env`，在服务器安全填写 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY`，重启服务。不要把密钥放进 `public/`、聊天或 GitHub 仓库。

配置后，页面的“整理方式”中会出现对应 AI 选项。资料只在点击该选项生成时发送给选定的服务商；导入图片不会上传给 AI。未配置接口时使用模板，不会伪称 AI 已生成。API 服务的可用性、模型和额度以实际账号为准。

默认服务面向单用户本机开发。若将含 AI 密钥的 Node 服务暴露到公网，需另加登录鉴权、限流和 HTTPS；不要将它直接作为公开付费 API 服务。

## 数据与验证

草稿和图片保存在当前浏览器的 IndexedDB，不会通过 GitHub Pages上传到服务器。不同设备不共享数据，清除浏览器数据会删除记录。单图最大 10 MB，总图片最大 50 MB，最多 20 张；不支持 HEIC，需先转换成支持的格式。

`npm test` 覆盖实际 HTTP 生成流程、输入校验、跨站请求限制、静态文件隔离、AI 调用模拟和 ZIP 原始字节保留。真实外站检索、真实 AI 账号以及手机实机行为需要独立验证。
