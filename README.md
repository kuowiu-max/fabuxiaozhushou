# 发布小助手

可直接导入 AI 的技能。输入门店名称，生成自然口吻的原创文字，并从正常可访问的小红书帖子、美团评论页获取对应照片。无需网页或本地部署。

## 使用

1. 支持技能导入的 AI：下载并导入 [技能包](downloads/publish-helper.zip)。
2. 没有技能入口的聊天软件：上传 [提示词文件](downloads/publish-helper.md)，让 AI 按文件规则工作。
3. 发一句：“使用发布小助手：门店名称，城市。”

之后可以直接说“短一点”“换标题”“自然一点”“只给正文”。有同名门店时会询问城市或分店，也支持店铺链接和清晰截图。

用于大众点评分成时输入：“使用发布小助手，大众点评分成：门店名称，城市。”已依据用户于 2026-10-09 提供的“笔记创作分成活动规则”截图适配[指定活动](https://cube.dianping.com/cube/block/aa1a7b35bf4b/334177/index.html)：个人账号诚信分 12 分、系统邀请、确认授权后参与；现金收益在次月 5 日后的工作日可提现。收益由多个维度综合计算，无固定单篇金额保证。

用户另行提供的内容建议为图文不少于 **6 图、200 字**；视频不少于 **30 秒、200 字**。分成模式默认图文正文约 220–300 字、优先 6 张照片，缺素材按实际交付；用户选视频时可整理脚本／配文，是否能交付视频取决于 AI 实际工具与真实素材。保留原文“建议”的性质，不宣称达到数量就符合全部要求。

图片原创要求或 AI 内容政策尚未明确，授权协议全文也尚未取得；不能据此宣称抓取的评论图或 AI 草稿符合全部活动条件。网页在维护环境被网络代理拦截，条款依据为用户提供的截图及补充文字，未直接在线验证。原文摘录与适配范围见 [活动适配说明](skills/publish-helper/references/dianping-revenue.md)。

## 实际能力

- 核对具体门店、分店及来源，不混用不同门店的信息。
- 文案避免模板腔和“作为 AI”等自我说明；用真实资料写原创内容，不虚构作者到店经历，不承诺通过 AI 检测。
- 从可访问的真实帖子或评论发现、下载公开照片，默认 3–6 张，并保留原帖出处。
- 可以交付文件的 AI 可打包文案、照片及来源。缺少图片或文件能力时提供真实参考链接，不编造附件。

**技能不会给 AI 新增联网、浏览器、登录权限或图片工具。** 能否访问小红书、美团取决于该 AI 实际提供的工具和站点访问状态。普通聊天软件上传提示词不等于安装了抓取工具。

外站参考照片与自有／授权原图分开标注。公开可见不等于取得转载授权；下载保留原图，不额外添加或擅自去除水印。结果不自动发布。

外站评论图只作为参考素材，不能因为下载或去重就算作本人实拍。分成活动的原创、真实体验及图片条件按实际条款核对；文字写得自然也不能证明符合活动的 AI 内容要求。

## 文件

- `skills/publish-helper/`：完整技能及资源。
- `downloads/publish-helper.zip`：供 AI 导入的技能包。
- `downloads/publish-helper.md`：普通对话可上传的单文件提示词。
- `downloads/release.json`：版本、大小及 SHA-256。

包内脚本由具备执行能力的 AI 在其环境中使用，无需用户本地部署。完整技能见 [SKILL.md](skills/publish-helper/SKILL.md)。以前版本的网页文件保留在仓库，使用技能无需运行它们。

## 开发维护

以下仅供维护仓库，不是用户使用步骤：

```sh
npm run build:skill
npm run check:skill
npm test
npm run test:materials
```

打包使用 Node.js 22+，可选图片下载／素材打包脚本使用 Python 3.10+ 标准库。脚本不搜索页面、不绕过登录、不处理验证码或去除水印。源码更新后重新生成 ZIP 和提示词，CI 校验发布内容一致性。仓库不保存用户照片、登录资料或真实 API 密钥。
