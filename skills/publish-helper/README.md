# 发布小助手 v0.3

只需导入 AI 技能，无需打开网页、部署本地服务或配置 API 密钥。

加载后输入：

> 使用发布小助手：门店名称，城市。

技能会用该 AI 实际提供的工具核对门店、生成自然口吻的原创文案，并从可访问的小红书帖子或美团评论页获取真实照片。可接着说“短一点”“换标题”“自然一点”。

支持 Agent Skills 的 AI 导入 `publish-helper.zip`；没有技能入口的聊天软件，可以上传单文件提示词 `publish-helper.md` 并要求读取规则。这不等于给软件新增联网或图片工具。

`scripts/` 中的 Python 脚本供具备执行能力的 AI 在其运行环境内调用，用户不需要在自己的手机或电脑上运行。下载脚本只获取真实页面中已发现的公开图片，不处理登录或验证码，不去水印。图片保留出处，外站照片不自动获得转载授权。
