# 发布小助手技能

用于支持 Agent Skills 导入的 AI。加载后输入：

> 使用发布小助手：门店名称，城市。

`SKILL.md` 是完整技能指令。仓库的 `downloads/publish-helper.zip` 是同一技能的 ZIP 包，根目录包含 `publish-helper/SKILL.md`。请按所用 AI 的技能导入入口上传 ZIP；不同产品对 Skills 的支持和导入方式不同。

普通聊天软件若没有技能导入功能，可上传 `downloads/发布小助手提示词.md`，发送：

> 请读取这个文件并按其中的规则工作。门店是：门店名称，城市。

这是对话指令模式，不会为软件新增联网、自动抓取或图片处理工具，也不会自动成为永久安装的技能。技能需要的实际操作依赖该 AI 已有的能力；无法访问的外站内容不会被编造成搜索结果。

无需运行网页，不需要 API 密钥。
