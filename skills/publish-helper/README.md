# 发布小助手 v0.3.3

只需导入 AI 技能，无需打开网页、部署本地服务或配置 API 密钥。

加载后输入：

> 使用发布小助手：门店名称，城市。

技能会用该 AI 实际提供的工具核对门店，以消费者视角生成自然口吻的原创文案，并从可访问的小红书帖子或美团评论页获取真实照片。文案围绕怎么选、怎么点、预算和适用场景等已核实细节，有你的真实体验时直接用第一人称分享。可接着说“短一点”“换标题”“自然一点”。

用于大众点评分成时说：“使用发布小助手，大众点评分成：门店名称，城市。”已根据用户提供的活动截图适配：个人账号诚信分 12 分、系统邀请并确认授权后参与，现金收益在次月 5 日后的工作日可提现。用户补充的内容建议为图文不少于 6 图、200 字；视频不少于 30 秒、200 字，并确认允许外站照片及 AI 内容。图文默认正文约 220–300 字、优先 6 张照片，文字减少套话和模板腔，缺素材按实际交付。外站图与 AI 的允许状态依据为用户确认，未直接在线核验；建议不等于强制审核门槛，不保证分成资格。详见 `references/dianping-revenue.md`。

支持 Agent Skills 的 AI 导入 `publish-helper.zip`；没有技能入口的聊天软件，可以上传单文件提示词 `publish-helper.md` 并要求读取规则。这不等于给软件新增联网或图片工具。

默认交付只给文案和编号照片，不附照片出处、来源清单或素材记录文件。

`scripts/` 中的 Python 脚本供具备执行能力的 AI 在其运行环境内调用，用户不需要在自己的手机或电脑上运行。下载脚本只获取真实页面中已发现的公开图片，不处理登录或验证码，不去水印。打包默认使用 `--content-only`，只含文案和照片；外站照片不自动获得转载授权。
